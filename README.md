# hardware-practice

Series of practice problems and questions in preparation for digital logic design careers. Each module is written in SystemVerilog and focuses on a core building block commonly tested in hardware design interviews, sequential logic, counters, clock domain handling, and edge/pulse detection.

## Purpose

This repo is a personal practice log for digital logic design fundamentals, the kind of problems that show up frequently in ASIC/FPGA design interviews and coursework. Each file is self-contained and written to be simulated and verified independently.

## Tools

- **Language:** SystemVerilog
- **Simulation:** ModelSim
- **Synthesis:** Vivado
- **Editor:** VS Code with TerosHDL
